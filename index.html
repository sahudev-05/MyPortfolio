Acadly 🎓 — Complete Architecture & System Specification

System Overview

Acadly is an offline-first academic management, attendance forecasting, and productivity application engineered with Flutter (Dart 3) and Riverpod 3. It bridges rigorous offline SQLite storage (Drift) with real-time cloud synchronization (Google Firebase) to guarantee 100% data privacy, instant local execution, and seamless multi-device backup.

Verified Attendance Algorithms

Attendance Percentage
Percentage = (Classes Attended / Classes Held) * 100
Classes Needed for Target (T%)
Classes Needed = ceil( (T * Held - 100 * Attended) / (100 - T) )
Safe Margin Allowed to Miss
Can Miss = floor( (100 * Attended - T * Held) / T )
Hours Conversion
Avg Hours = Weekly Hours / Scheduled Days; Safe Hours = Classes * Avg Hours

Isolated Multi-User Drift SQLite Architecture

Each authenticated user receives a dedicated database file partitioned by their unique Firebase UID (acadly_$uid.sqlite). This guarantees absolute zero risk of data leakage between student accounts on shared tablets or lab devices.
